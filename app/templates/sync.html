Using it in Claude Code

Open a Claude Code session in the target repository. These project slash commands become available:

/sdlc-status
Stage status, feature implementation status from the code, coverage gaps, next actions.
/implement-feature FEAT-002
Reads the TSD, stories and the Dev Pack, then implements the feature with tests.
/qa-feature FEAT-002
Implements and runs the automated tests from the QA plan and reports pass/fail per case.

Re-sync after every approval so the repository always reflects the latest approved versions. Consider committing .sdlc/ and .claude/commands/ so the whole team shares them.
